# Directrices de UX/UI - Spotifake

## Principios de Diseño
- **Simplicidad:** Mantener las interfaces limpias; solo mostrar lo que el usuario necesita en cada momento.
- **Consistencia:** Usar los mismos iconos, colores y tipografía en toda la aplicación.
- **Feedback Inmediato:** Cada acción (clic, swipe) debe tener una respuesta visual o háptica instantánea.
- **Accesibilidad:** Contraste de colores adecuado, soporte para lectores de pantalla y tamaños de fuente ajustables.

## Componentes Clave
- **Navigation Bar:** Fácil acceso a Home, Search y Library con una sola mano.
- **Mini-Player:** Siempre visible mientras se navega, permitiendo control básico (Play/Pause) sin interrumpir la exploración.
- **Gesto de Deslizamiento (Swipe):** Implementar gestos intuitivos en listas para añadir a la cola o marcar como "Me gusta".

## Paleta de Colores (Referencia)
- **Fondo:** Oscuro (#121212) para reducir la fatiga visual.
- **Primario:** Verde vibrante (#1DB954) o un color distintivo para Spotifake.
- **Texto:** Blanco con alta opacidad para legibilidad y gris para metadatos.

## Micro-animaciones
- **Transiciones:** Suavidad al abrir el reproductor a pantalla completa usando animaciones compartidas (Shared Elements).
- **Carga (Shimmer):** Uso de efectos de brillo en lugar de spinners para mejorar la percepción de velocidad.
